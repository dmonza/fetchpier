## Descriptive use

You may make truthful, descriptive references such as:

- "Forked from Fetchpier"
- "Based on software originally created by Daniel Monza"
- "Originally developed as a Sincrum project"
- "Compatible with Fetchpier"
- "Imports Fetchpier collections"

Such references must not imply that your version is the official version or that it is endorsed by Daniel Monza or Sincrum. When in doubt, add a disclaimer clarifying the relationship.

## Why this separation exists

This is a standard pattern in open-source projects with a clearly identified maintainer. The reasoning is straightforward:

- **The code is meant to be free** for anyone to use, modify, and redistribute. That is what the MIT License is for.
- **The brand identifies the official project** and its origin. Users searching for Fetchpier need to know which version is the original, which version is maintained by the original author, and which versions are independent forks.

Keeping these two layers separate is what makes both possible. A fork can take all the code; it cannot present itself as the original.
